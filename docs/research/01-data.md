# 1. 데이터 조사

> 조사일: 2026-11-04 · 방법: 웹 검색과 공식 페이지 열람 (파일은 내려받지 않음)
> 표기: **확인** = 공식 페이지에서 직접 확인, **미확인** = 페이지에 없거나 파일을 열어봐야 알 수 있음

## 1. 결론 (데이터 사용 가능 여부)

**부분적으로 사용 가능. 장바구니 모델은 성립할 가능성이 높지만, 경위서 텍스트는 공개 데이터에서 확인되지 않았다.**

- 소방청 `연간화재통계`(CSV, 이용허락 제한 없음)가 화재별 피해를 담고 있다고 설명되어 건 단위로 보이나, 행 수와 기간은 미확인이다.
- NFDS 사이트의 공개 통계는 집계 통계뿐이며, 건 단위 원자료 다운로드는 확인되지 않았다.
- 경위서·화재조사서 텍스트는 공개 데이터에 없다. 현재 README의 Stage 1(Solar 태그 추출)은 입력 텍스트가 없어 그대로는 성립하지 않는다.
- 기상은 기상청 ASOS 시간자료 API로 결합할 수 있다. 단, 화재 데이터의 위치가 시군구 수준이라 가까운 관측 지점에 매핑하는 방식이 된다.

## 2. 후보 데이터셋

### 2.1 소방청_연간화재통계 (주 후보)

- 출처: [data.go.kr 15060386](https://www.data.go.kr/data/15060386/fileData.do)
- 제공기관: 소방청 화재대응조사과 · 형식: CSV · 갱신: 연 1회 · 수정일: 2025-11-18
- 이용허락범위: 제한 없음
- 건 단위 여부: 설명에 "각 화재별 인명 피해자 및 재산 손해"가 있어 건 단위로 추정 (**미확인**)
- 행 수, 수록 기간, 다운로드 시 로그인 필요 여부: **미확인**

컬럼 (17개, 페이지 기준):

| 구분 | 컬럼 |
|---|---|
| 시간 | 일시 (시각 포함 여부 **미확인**) |
| 장소 | 시도, 시_군_구, 장소대분류, 장소중분류, 장소소분류 |
| 화재 | 화재유형 |
| 발화 | 발화열원 대/소분류, 발화요인 대/소분류, 최초착화물 대/소분류 |
| 피해 | 인명피해(명) 소계, 사망, 부상, 재산피해 소계 |

텍스트(서술형) 컬럼은 없다. 원인은 코드형 분류로만 제공된다.

### 2.2 소방청_가스누출(폭발) 화재 발생 현황 (보조)

- 출처: [data.go.kr 15143534](https://www.data.go.kr/data/15143534/fileData.do)
- CSV · 연 1회 갱신 · 등록 2026-09-28 · 이용허락 제한 없음 · 근거: 국가화재정보시스템
- 컬럼: 화재발생년월일, 시도, 시군구, 발화요인대분류, 최초착화물 대/소분류, 사망, 부상
- 가스 관련 화재에 한정되어 전체 분석에는 부적합. 건 단위 여부, 행 수, 기간은 **미확인**.

### 2.3 소방청_화재인명피해 지역별 성별 인원 현황 (사용 불가)

- 출처: [data.go.kr 15044002](https://www.data.go.kr/data/15044002/fileData.do)
- 시도 × 성별 × 연도 집계표(2010~2017). 장바구니 모델에 쓸 수 없음.

### 2.4 소방활동·출동 관련 API

- 소방청 일일소방활동상황: [data.go.kr 15052714](https://www.data.go.kr/data/15052714/fileData.do) — 전국 일별 집계(메타데이터상 PDF). 건 단위 아님.
- 소방출동 정보(행정안전부 생활안전지도 연계): [data.go.kr 15101871](https://www.data.go.kr//data/15101871/openapi.do) — WMS 형태, 18개 지역 한정. 상세 내용은 검색 결과 요약만 확인했고 페이지 본문은 열람하지 않음 (**미확인**).
- 소방청 구급정보 REST API: [data.go.kr 15099423](https://www.data.go.kr/data/15099423/openapi.do) — 화재가 아니라 구급 정보. 개발계정 1,000건, 무료.

### 2.5 NFDS 사이트 (nfds.go.kr)

- 화재통계(`/stat/general.do`): 구분, 화재건수, 사망, 부상, 인명피해 계, 재산피해 등 **집계 결과**를 보여줌. 다운로드 형식은 페이지에서 확인되지 않음.
- 화재추세분석(`/stat/trend.do`): 연·월·일·요일·시간대 단위 집계 차트. 건 단위 아님.
- 화재통계연감: [게시판 B21](https://www.nfds.go.kr/bbs/selectBbsList.do?bbs=B21) — 2016~2025 연감이 PDF로 게시됨(1쪽 기준, 이전 연도는 미열람).
- 화재보고서: [게시판 B26](https://www.nfds.go.kr/bbs/selectBbsList.do?bbs=B26) — 교육·강의 자료 위주. 개별 화재조사 보고서는 1건(공장 화재) 확인. 정기 공개 여부는 **미확인**.
- 정보공개 메뉴는 홈페이지 내비게이션과 사이트맵에서 확인되지 않음.
- 참고: 2007~2012년 NFDS 화재조사데이터는 변수 183개라는 연구 보고가 있음 ([KoreaScience](https://koreascience.kr/article/JAKO201414753675816.pdf) 등). 현행 공개 컬럼과 같다고 볼 수 없음.

## 3. 기상 데이터

- 기상청 ASOS 시간자료 API: [data.go.kr 15057210](https://data.go.kr/data/15057210/openapi.do)
- REST, JSON/XML, 무료, 개발계정 10,000건, 종료일은 전일(D-1)까지
- 요청 변수: `dataCd=ASOS`, `dateCd=HR`, 시작/종료 일시, `stnIds`(지점번호)
- 관측 요소: 기온, 강수량, 습도, 기압, 풍향, 풍속 등 (실효습도는 직접 제공되지 않고 일평균 습도 등으로 계산해야 하는지 **미확인**)
- 지점번호는 기간별 위치가 달라질 수 있어 위경도 변경 이력 확인이 필요하다고 안내됨.
- ASOS는 주요 도시 중심이고 AWS는 촘촘한 지역망이다. 시군구 → 가까운 ASOS 지점 매핑 방식이 필요.

## 4. 핵심 질문에 대한 답

1. **건 단위인가, 집계인가?** 연간화재통계는 건 단위로 추정(미확인). NFDS 웹 통계는 집계. 파일을 열어 행 수를 확인해야 확정된다.
2. **경위서 텍스트가 공개되는가?** 확인되지 않았다. 코드형 분류(발화요인·열원·착화물)가 대안 아이템이다. 대안 방향은 이후 논의가 필요하다 (아래 5절).
3. **일시·장소 수준은?** 장소는 시군구까지(건물 단위 아님). 일시는 컬럼은 있으나 시각 포함 여부 미확인. 시각이 없으면 시간 단위 기상 결합은 불가능하고 일 단위까지만 가능하다.
