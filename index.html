    1. 실제 건물 폴리곤 & 속성 공식 다운로드 경로

    ① 건물 모양 (폴리곤 공간정보)

    • 브이월드(V-World) / 국가공간정보포털: GIS건물통합정보 (Shapefile, 건물관리번호·연면적·층수 포함)
    • 도로명주소 개발자센터: 건물 도형 및 전자지도 (읍면동별 최신 건물 윤곽선)

    ② 건물 상세 속성 (건축물대장 & 소방)

    • 국토교통부 건축HUB / 공공데이터포털: 건축물대장 표제부 API (실제 사용승인일, 주구조, 주용도, 지붕구조)
    • 소방청 / 국가화재정보시스템(NFDS): 화재발생정보, 전국 소방용수시설(소화전) 현황

    2. 내 GeoJSON / CSV 데이터 바로 불러오기

    브이월드·QGIS에서 변환한 GeoJSON 파일(폴리곤 교체)이나, 공공데이터포털에서 받은 CSV 속성 파일(id 또는 name 기준으로 기존 건물에 속성 병합)을 선택해 지도에서 바로 확인할 수 있습니다.
