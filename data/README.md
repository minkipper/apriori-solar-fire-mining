# data/ — 데이터 폴더 규칙과 목록

## 폴더 구조

```
data/
├── README.md        ← 이 파일 (규칙 + 데이터 목록)
├── raw/             ← 받은 원본 그대로. 절대 수정하지 않음
│   ├── nfa/         ← 소방청 (National Fire Agency)
│   └── <출처>/      ← 예: kma(기상청), molit(국토교통부)
└── processed/       ← 코드로 만든 가공 데이터 (필요할 때 생성)
```

## 규칙

1. **원본(`raw/`)은 수정하지 않습니다.** 인코딩 변환, 컬럼 정리 등은 코드로 처리하고 결과는 `processed/`에 저장합니다.
2. **출처별 폴더**에 넣습니다. 새 출처면 영어 소문자 약어로 폴더를 만듭니다.
3. **파일 이름:** `<출처>_<내용>_<기간>.<확장자>` (영어 소문자, `_`로 연결)
   - 예: `nfa_fire_stats_2024.csv`, `kma_asos_hourly_2024.csv`
   - 한글·공백이 들어간 파일 이름은 OS·도구에 따라 깨질 수 있어 사용하지 않습니다. 원래 이름은 아래 목록에 기록합니다.
4. **데이터를 추가하면 아래 목록에 한 줄을 추가합니다.** (목록 없이 파일만 올리지 않습니다)
5. 50MB 이상 파일은 올리기 전에 팀에 알립니다. 100MB를 넘으면 GitHub가 거부합니다.
6. 개인정보가 포함된 데이터는 올리지 않습니다.
